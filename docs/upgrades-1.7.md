# 1.7.0：流畅度、强白柔过渡与界面精简

## 边缘问题与修复

旧的光学模型使用较陡的亮度参与权重。强白柔的有符号光能重分配在低反差交界可能过度减去较亮一侧的光能，生成反向亮边。190/150 中性灰阶边界在旧版产生约 26 个 8 位灰阶的反向跳变。提高强白柔的基础参与量，同时保留平滑高光权重后，亮度扫描测试的最大反向变化控制在 1 个灰阶以内；16 位输出与预览一致。

此调整用于光学模型，经典六档的参考像素保持逐字节一致。单调边界是针对明暗轮廓的回归，不代表所有真实照片、反差、色彩和实体滤镜都已标定。用户提供的照片裁片仅用于本机观察，不进入公开仓库或安装包。

## 保持画质的性能优化

- 预览仍为最长边 1200 px，最终仍按保留的原尺寸源图、原有散射层数和 16 位读写计算。
- 热点内将 Math 绑定为局部引用，减少重复全局查找；不改变经典计算顺序或数值公式。
- 连续输入在 90 ms 内合并；新参数立即使旧请求失效，计算期间可继续调节。保存前仍校验最终预览与参数一致。
- 条带上限从 262144 增为 1048576 像素、每批最多 128 行，6000×4000 输出写入从 125 次减为 32 次。磁盘数据缓存每个数据集最多保留 2 条带；用更多有界缓存换取更少原生调用，不将全部全图中间数据驻留 JS 内存。
- 删除 PS 局部蒙版与按住比较的运行路径；删去重复样式和常规布局诊断。界面无实时背景模糊、装饰动画或额外 UI 框架。

同机、同一 Node.js 进程交替运行三次 1200×800 RGB8 合成图、光学白柔 1/2 的独立同步计算：旧版为 2168 / 2827 / 4106 ms，新版为 1341 / 1244 / 1787 ms，中位数约 2.83 → 1.34 秒。这是 VM 热点诊断，不包含 Photoshop 写入和磁盘保存，不能据此承诺宿主整体同比提速。

## 界面与局部功能

参考 Apple HIG 的字体层级、留白与清晰结构，以石墨灰底色、蓝色强调、克制圆角组织参数。说明文字为 13 px，参数标签为 14 px。仅显示版本号，不在界面显示作者信息；项目来源与权利仍保留在 CREDITS.md。

Photoshop 局部柔光入口和蒙版处理模块已删除。已有独立图层蒙版不会被主动删除；重新编辑柔光内容后，外层蒙版仍属于 Photoshop 文件本身。Camera Raw 18.5 的三个 XMP 原生蒙版预设保持原样，继续在选中蒙版后套用。

## 验证范围

`node --test tests/*.test.cjs`：14 个测试文件全部通过，覆盖经典输出兼容、强白柔单调边界、预览/16 位一致性、输入合并、过期取消、原图位深、失败回滚、缓存和参数恢复。

Windows / Photoshop 2026（27.9.1）实机验证：

- 新版首页与参数界面显示正常，说明文字增大；没有按住对比、PS 局部柔光及作者入口。
- 连续点击白柔 1/2 → 黑柔 1/4 → 白柔 1/2，最终预览采用最后选择的档位。
- 1600×1066 RGB16 测试图：光学白柔 1/2 保存、再次编辑、切换黑柔 1/4 并更新原对象成功；保存 PSD 中嵌入的 PSB 头为 1600×1066、16 位。
- 6000×4000 RGB16 测试图：光学黑柔 1/8 原尺寸输出成功，宿主返回源图 RGB16，图层名为 `ThisPC 柔光 1`。从点击保存到完成日志约 184 秒；上版同图同档单次记录约 198 秒。两次不是多轮受控宿主跑分，大图保存仍需等待。
- 测试期间未发生插件闪退；这不能替代长时间压力测试。Camera Raw 三个 XMP 与上版逐字节内容一致，未重新修改预设效果。

公开仓库、ZIP、安装目录与本机镜像按文件核对；不包含测试 PSD、日志或用户照片。

仍未完成广色域标定、macOS、跨版本和长时间压力测试。实体柔光镜配对标定与过曝恢复不在本项目保证范围内。
