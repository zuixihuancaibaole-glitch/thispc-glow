# 1.5.2 预览响应与稳定性

本次保留现有 1200 px 最终工作长边、快速预览长边、光晕层次、光学参数和效果强度。优化计算调度与 PS 写入方式，不通过减少像素或迭代次数加速。

## 已确认的问题与修复

1. **同步散射阻塞 UI**：旧版一次计算期间无法处理界面事件。新版按小块计算，约每 12 ms 让出执行权；过期任务在计算阶段提前退出。同步和异步入口共用同一算法。
2. **预览反复替换智能对象**：旧版每次更新写 PNG，再导入新智能对象、校验和删除旧图层。新版在支持 Imaging API 的宿主内直接更新已有像素图层。已有内部智能对象第一次更新时栅格化，外层保存结果仍是可再次编辑的智能对象。
3. **16 位源文档整图转换**：旧版读取前将原图改为 8 位，随后转回 16 位。转回不会找回丢失的精度。新版使用 `getPixels({componentSize:8,targetSize:...})` 仅取得小尺寸预览，原文档不切换位深。
4. **无尺寸限制的重试**：旧版像素读取失败后会移除 `targetSize`，可能分配整张大图。新版重试保留目标尺寸；失败时报错，避免意外整图分配。
5. **重复蒙版上传与临时文件**：已有像素预览保留蒙版时复用它；同尺寸蒙版不再额外复制。旧写入通路产生的临时 PNG 在更新结束后清理。原生图像缓冲在成功和失败路径都调用 `dispose()`。

预览写入在一段历史事务中完成，出错时回滚，避免半更新状态；不清空用户历史记录或更改 PS 性能首选项。没有改变原图、已有光效或用户预设的格式。

## 算法与响应验证

1200×800 合成图、本机 Node.js 测量：

| 操作 | 1.5.1 算法耗时 / 连续无事件时段 | 1.5.2 算法耗时 / 最大心跳间隔 |
| --- | --- | --- |
| 首次散射 | 1107 / 1107 ms | 1442 / 40 ms |
| 改识别范围 | 1192 / 1193 ms | 1358 / 33 ms |
| 改扩散半径 | 1182 / 1182 ms | 1400 / 40 ms |
| 仅改颜色，复用散射 | 240 / 241 ms | 264 / 27 ms |

这是算法调度微基准，不包含 Photoshop、PNG、磁盘和图层写入时间；不是整个插件加速倍数。主动让出线程会增加一些独立计算的墙钟时间。最大心跳间隔包含系统定时器等待，不是所有机器都能保持相同数值。直接像素写入消除了旧通路的额外导入工作。

六档预设均与 1.5.1 参考图逐字节一致；另对最小/最大半径、十层散射、色相偏移及零强度做差分验证。持续回归使用 `tests/scattering-1.5.1-golden.json` 的固定摘要；异步入口也验证与同步入口一致。

```powershell
node --test tests/*.test.cjs
```

自动测试还验证：16 位原图不发生位深转换；所有重试都有目标尺寸；像素缓冲释放；预览图层 ID 稳定、没有 PNG 编码及新对象导入；一次历史提交与失败回滚；过期任务不写入 PS；局部蒙版缩放、密度、羽化、保存和取消。

## 本机实测

Windows / Photoshop 2026 27.9.1.1，以 6000×4000、RGB 16 位合成 PNG 验证：

- 创建柔光成功，原图仍为 16 位，工作文档按既有设置生成 1200×800 预览。
- 黑柔、白柔切换、颜色调整和高光范围调整成功；快速预览后保存会重算最终工作尺寸。
- 保存回原图，重新编辑，再保存仍更新同一智能对象。
- 从整图选区创建局部蒙版，切换白柔预设后保存成功，原图保持 16 位。
- 测试期间未产生新的 Photoshop 崩溃转储。未将这次短时测试视为长期稳定性保证。

此次局部实测使用整图选区；部分选区的坐标、密度、羽化和取消保护由自动回归覆盖，前版另有小图局部实测。没有在本次自动化中逐个读取历史面板记录和所有蒙版属性。

## 范围与限制

系统日志存在旧版 PS 原生 `0xc0000005` 崩溃记录。现有日志不能证明某一脚本调用就是该原生异常的唯一原因；这次修复已确认的阻塞和额外操作，不能承诺彻底消除所有闪退。

新版主散射模型使用分段调度。旧对象兼容渲染和十字星光保留原计算路径。没有安装新运行依赖，也没有关闭 GPU、削减迭代、降低最终分辨率或清理用户历史。

跨版本、macOS、所有广色域场景及数小时压力测试尚未完整验证。

接口依据：[Adobe Imaging API](https://developer.adobe.com/photoshop/uxp/2022/ps-reference/media/imaging)、[Adobe executeAsModal / history suspension](https://developer.adobe.com/photoshop/uxp/2022/ps-reference/media/executeasmodal)。
