# 1.6.0 实现与验证

## 输出与再次编辑

新建光效前，先将当前合成图保存为临时完整 PSB。预览依旧使用最长边 1200 px 工作图；最终保存重新打开完整源图，按原始像素尺寸计算。光晕、源图、状态与格式标记共同嵌入智能对象。重新编辑时先单独保留该对象的完整原位深源图，再生成 8 位小尺寸预览，保存时重新计算原尺寸结果，保留原图层位置、可见性、混合模式与不透明度。

原尺寸计算使用有界条带和临时磁盘缓存，避免把所有多尺度大图同时保存在 JavaScript 堆。完整源图、输出 PSB 和 Photoshop 自身的原生缓冲仍占内存与磁盘，不能保证峰值内存恒定或更快完成。输出文档的像素写入合并到单个历史事务；计算、结构校验、元数据和 PSB 保存成功后才替换原图中的结果。失败保留工作预览供重试。

旧版对象保持其原有渲染模型和工作尺寸；插件不能补回旧文件未保留的原始细节。透明图像暂不支持原尺寸输出，请先添加背景。原尺寸上限为 2.5 亿像素。

## 光学模型与局部范围

新版模型计算多尺度光源模糊与原光源之间的有符号差值。在未裁切、未改色的中性测试中，降低峰值并向周围分配光能；最终显示值仍可能被色域与 0–1 裁切改变。不是经过实物标定的滤镜，sRGB 线性化只是近似。

局部计算保留蒙版边界外三次盒式卷积的完整核支持。羽化扩大计算范围，超大光晕可能退化为全图计算。输出仍通过独立像素蒙版控制覆盖区域，避免两次遮罩。

## 对比与恢复

按住查看原图会保存并暂时改变源图、柔光、识别层的可见性；释放、移出、窗口失焦、更新和保存都会恢复。恢复上一次参数切换最近两次成功预览的参数。异常退出恢复仅保存参数，不保存照片、选区或蒙版，也不能代替 PSD 保存。

## 自动验证

运行 `node --test tests/*.test.cjs`：14 个测试文件覆盖旧同步/异步像素一致性、调度与取消、经典六档输出逐字节回归、分条读写上限、完整/局部一致性、范围外光源、未裁切光能守恒、原生缓冲释放、历史失败回滚、蒙版保留、对比恢复、参数草稿及明确图层 API 与精确 ID 锁定。

## 实机验证与剩余范围

在 Windows / Photoshop 2026（27.9.1）已用 1600×1066、RGB 16 位合成图完成新建原尺寸保存、关闭后重开 PSD、再次编辑、连续切换黑白柔、参数回退和更新原有智能对象。检查保存后 PSD 内嵌 PSB 文件头，尺寸仍为 1600×1066、16 位。临时编辑预览使用 8 位，完整主副本保持原位深。6000×4000、RGB 16 位合成图也完成原尺寸智能对象保存，黑柔 1/8 的本次保存约 3 分 20 秒（包含原尺寸计算、PSB 保存和嵌入），不是小预览的响应时间，也不是所有照片的性能保证。局部功能用矩形选区完成创建、原尺寸保存和重新编辑，独立蒙版的 20 px 羽化得以保留。未完成跨版本、macOS、广色域标定与长时间稳定性压力测试；不能承诺彻底杜绝 Photoshop 闪退。Camera Raw 18.5 的原生蒙版预设沿用此前版本，不运行此散射算法。
