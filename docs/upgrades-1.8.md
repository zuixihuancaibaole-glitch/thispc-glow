# 1.8.1：快速模式、黑柔增强与边缘修复

## 快速模式

默认开启，直接复制已完成的预览为可编辑智能对象，最长边 1200 px、8 位，再铺满原照片画布。保存跳过完整源图读取、原尺寸散射重算和全图磁盘缓存；原照片图层的像素和位深不变。

关闭快速模式可按原尺寸计算，保留完整源图与原位深。首次创建仍暂存完整源图，方便在保存前选择两种方式，因此创建仍需要读取与预览准备时间。

快速对象只保留预览尺寸源图；需要完整细节时，请关闭快速模式并从原照片创建。快速对象再次编辑时会提示此限制并维持快速输出。编辑旧的完整对象时默认关闭快速模式，避免自动降低已有细节。失败只清理临时副本，不替换原对象；保存后仍需另行保存 PSD。

## 默认强度与增强

黑柔和白柔 1/8 / 1/4 / 1/2 的默认强度分别为 65 / 80 / 100。黑柔的范围分别为 75 / 95 / 120，饱满度为 60 / 60 / 110，高光识别参数为 0.04 / 0.06 / 0.10；层数仍为 5 / 7 / 7。

中性日光纹理夹具的暗侧抬升：滤色模型从旧版约 7.29 / 10.60 / 16.04 增为 9.74 / 14.83 / 20.77，光学模型从约 7.34 / 10.65 / 15.95 增为 9.91 / 14.97 / 20.97。这是特定夹具的结果，不是所有照片的固定提升倍数。灯光夹具也检查近远衰减及三档递增。

旧对象参数与已存像素不自动改写；重新点击档位才应用新默认强度。重新编辑黑柔时会采用新曲线，外观可能变化。历史白柔参数的参考像素保持；白柔 1/2 边缘修正和 Camera Raw 三个 XMP 不变。

## 修复强度 100 的边缘

旧提取将亮度乘以陡峭的高光权重，再减去自身光能。较强扩散时，提取斜率过大，可能使边缘残差反转。灰阶扫描在光学黑柔 1/2 复现约 35 个灰阶的反向跳变；滤色模型的渐变边缘也能复现较小反转。

新版按 RGB 通道提取平滑高光能量，将曲线斜率限制在 0～1。保留基础扩散参与量及有界增益，让黑柔明显但不产生反向轮廓。先限制最大增益，再应用用户强度，使强度滑块全程响应。预览与原尺寸输出共用该曲线，没有新增散射层数或大图处理。

两个模型、三档黑柔均在强度 100 下扫描灰阶边界；加入带色边缘、4 / 12 / 32 px 柔边、提取斜率、强度响应和 16 位条带一致性检查。当前灰阶夹具最大反向跳变为 0。用户截图只用于本机观察，不进入仓库或 ZIP。

## 验证与限制

`node --test tests/*.test.cjs`：17 个测试文件通过。覆盖边缘单调性、增强与档位区分、强度 0～100、快速保存跳过全图计算、光学/滤色输出、失败保护、源位深、取消、回滚与恢复。

同一快速保存路径已在 Windows / Photoshop 27.9.1 的本机候选版验证：6000×4000 RGB16 原图，保存预览 1200×800，首次保存和再次编辑保存均约 2 秒；原图仍为 6000×4000、16 位。上版原尺寸保存记录约 184 秒。两种输出细节不同，不能视为相同画质的提速比例。

最终边缘曲线与新默认强度已通过自动回归，尚未完成 Photoshop 原始照片实机复核；长时间、macOS 与跨版本稳定性也未完整验证。快速模式牺牲柔光对象细节及位深，不能通过放大恢复。
